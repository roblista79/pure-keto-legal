# Pure Keto legal pages

Public pages for the Pure Keto app, served by GitHub Pages:
privacy.html (the Privacy Policy URL in App Store Connect), terms.html,
delete-account.html and index.html.

The source is the website/ folder in the keto-coach repo, where
scripts/tests/website.test.mjs keeps these pages in step with the in-app
Privacy Policy and Terms. Change them there, then copy them here.
